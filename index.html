Frequently Asked Questions

Do I need to know how to code or use Linux already?

Not at all. The whole point of 1-on-1 training is that we set everything up together, walk through plain-English commands, and leave you with a simple cheat sheet so you can talk to your AI workstation naturally.

Do I have to wipe Windows or macOS to use Athena OS?

No. Most clients either repurpose a spare laptop / affordable mini-PC into a dedicated Athena OS command center, run Athena OS inside a virtual machine, or install the full AI agent & memory stack directly onto their existing Mac or Windows machine.

Are there expensive monthly software fees after setup?

Athena OS, Python, local browser automation, GitHub CLI, and Context7 docs are 100% free. Optional cloud tools like Honcho memory or Firecrawl scraping start with generous free tiers, and you only connect the services you actually need.

Is it safe to connect my email and work files to AI agents?

Yes — security is built in from step one. Commands run sandboxed, API keys are automatically redacted from memory logs, and we configure strict human-in-the-loop rules so the AI queues drafts and asks your confirmation before sending emails or making external changes.

Can we do this remotely, or only in Calgary?

Both! I work with clients across Canada and the US over live screen-share, and also offer in-person setup sessions in Calgary, AB.
